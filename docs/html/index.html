About Me

가비아 클라우드 개발팀에서 Openstack 기반 클라우드 플랫폼 시스템 개발에 참여하고 있는 백엔드 개발자 입니다.
Python을 주로 사용하며, FastAPI 프레임워크를 사용해 API 서버를 개발하고 있습니다.
Python 애플리케이션을 유지보수 가능하게 설계하고, 개선하는 것에 관심이 많습니다.


  • REST API 설계/구현, DB 모델링, 아키텍처 개선, 레거시 개선, 파이프라인 설계/구현 업무 수행.

  • CI/CD, 업무 자동화 스크립트를 활용해 업무 프로세스를 개선.

  • 기술 공유와 오픈소스 컨트리뷰션에 관심이 많아 기여/멘토링 관련 활동에 참여.
