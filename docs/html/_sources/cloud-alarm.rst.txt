클라우드 자원 사용률 알람 서비스
================================

프로젝트 개요
-------------

핵심 기능
---------

* 클라우드 자원의 ``CPU``, ``메모리``, ``디스크`` 사용량에 대한 알람 설정
* 클라우드 자원의 ``네트워크`` 사용량에 대한 알람 설정
* 모니터링 시스템 (Zabbix, 네트워크 트래픽 모니터링 시스템)과의 연동
* 모니터링 시스템으로 부터 발생하는 알람 신호 처리
* 알람 발송 처리 (``SMS``, ``Email``)

개발 환경
---------

- FastAPI, Sqlalchemy, alembic
- Python Apscheduler
- Dependency injector
- MySql
