클라우드 자원 사용률 알람 서비스

수행기간 : 2024.09 ~ 2024.11 (3개월)

프로젝트 개요

  • 클라우드 자원 [1] 의 사용률을 모니터링

  • 사용률이 일정 수준 이상(임계치)으로 증가할 경우 등록된 사용자에게 알람 발송

핵심 기능

  • 클라우드 자원의 CPU, 메모리, 디스크, 네트워트 사용량에 대한 알람 설정

  • 모니터링 시스템 [2] 과의 연동

  • 모니터링 시스템으로 부터 발생하는 알람 신호 처리

  • 알람 발송 처리 (SMS, Email)

역할 및 기여

  • 시스템, 소프트웨어 아키텍처, DB 스키마 설계

  • FastAPI 서버 구현

  • 네트워크 트래픽 수집 스케줄러 구현

  • 프로젝트 매니저

개발 환경

  • FastAPI, Sqlalchemy, alembic

  • Python Apscheduler

  • Dependency injector

  • MySql

아키텍처

  • cloud-alarm 서버를 통해 알람 정보 등록/전송 프로세스 관리

  • 자원타입(인스턴스, 네트워크)에 맞는 모니터링 서버와 통신하며 알람 기능 제공

  • kafka 큐를 사용해 알람 메시지 발송 처리

의존성 구조

  • Facade 패턴을 사용해 서비스 간 의존성을 최소화

  • 서비스 로직 재사용성 향상

ERD

성과 및 결과

  • 서비스의 안정적 배포/운영

  • 모니터링, 알람 관리, 발송 시스템을 분리해서 구현

    • 시스템 분리를 통해 유지보수 가능한 시스템 구축

    • 장애 전파 범위 최소화

    • 서비스 확장성 확보

[1]

클라우드 자원: 인스턴스, 네트워크, 스토리지 등 클라우드 서비스의 자원

[2]

Zabbix, TMS: 모니터링 시스템
